# 1. Title:  TOPOPLACER: TOWARDS PHYSICALLY FEASIBLE 3D OBJECT RE-PLACEMENT VIA TOPOLOGY-AWARE BOX REASONING

# 2. Abstract 
Language-conditioned 3D object re-placement is essential for embodied agents that rearrange real-world environments. Existing approaches can identify semantically suitable placement regions, but typically represent placement as a point, region, or spatial mask, without explicitly accounting for the spatial extent and orientation of the object being placed.  Meanwhile, methods that estimate full object poses often assume access to a separately provided 3D asset. Consequently, physically feasible re-placement using objects directly observed in the scene remains underexplored. We observe that placement feasibility is largely determined by the spatial topology between an object's 3D bounding box and the surrounding scene geometry, including support, clearance, and collision constraints. Based on this observation, we formulate the task as source-box-conditioned 4-DoF placement prediction and propose TopoPlacer, a topology-aware box reasoning framework. TopoPlacer adopts a coarse-to-fine architecture. First, the source object is grounded as a 3D box, and Language-Guided Multi-Scale Placement Querying (LMPQ) predicts a voxelized placement likelihood field from which spatially diverse placement queries are initialized. Second, Pose-Aligned Boundary-Space Reasoning (PABR) uses the source-box geometry to iteratively refine and score the position and yaw of each query through topology-aware reasoning over object and scene boundaries. We further introduce RePlace3D, a large-scale benchmark containing 78,506 language-conditioned instances with dense feasible placement centers and center-specific yaw annotations. Experiments show that TopoPlacer improves both placement accuracy and physical feasibility over existing approaches.
